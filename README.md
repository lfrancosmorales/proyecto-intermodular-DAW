# Scena

## 📝 Descripción
Aplicación para visualizar las fiestas en mallorca.

## 🛠️ Stack Tecnològic

### **Frontend: La Experiència Visual**
* **Framework:** Angular + TypeScript (SPA).
* **Gestió del Mapa:** Leaflet.js amb OpenStreetMap.
* **Estils i UI:** Bootstrap 5.

### **Backend: El Motor Lógico**
* **Llenguatge i Framework:** Java 17+ amb Spring Boot 3.
* **Seguretat:** Autenticació mitjançant JWT (JSON Web Tokens) i Spring Security.
* **Documentació:** Swagger / OpenAPI per a la gestió d'endpoints.

### **Base de Dades: El Corazón Geográfico**
* **Motor:** PostgreSQL.
* **Extensió Espacial:** PostGIS (Imprescindible per a consultes de proximitat i filtrat per coordenades).
* **Persistència:** Spring Data JPA / Hibernate.

### **Infraestructura**
* **Contenidors:** Docker per a l'homogenització dels entorns de desenvolupament i producció.

## 📂 Estructura del Repositori
* `/docs`: Documentació técnica, diagrames de base de dades i dissenys de la interfície.
* `/src`: Codi font del backend i frontend (en desenvolupament).
